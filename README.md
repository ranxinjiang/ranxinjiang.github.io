# ranxinjiang.github.io
 
Personal portfolio site for **Ran Xin Jiang** — M.S. Information Systems (Data Analytics) at Baruch College, Zicklin School of Business.
 
**Live site:** [ranxinjiang.github.io](https://ranxinjiang.github.io)
 
## About
 
My work sits at the intersection of data analytics, product operations, and project management — turning ambiguous problems into workable processes and systems. This site collects my projects, experience, and certifications.
 
## Built with
 
Hand-built with HTML, CSS, and JavaScript. No framework, no build step. Hosted on GitHub Pages.
 
## Structure
 
```
.
├── index.html          # Home
├── about.html          # About Me
├── experience.html     # Experience timeline
├── projects.html       # Projects
├── certifications.html # Certifications
├── css/
│   └── style.css       # Site styles
├── js/
│   └── main.js         # Nav + interactions
└── img/                # Photos, project thumbnails
```
 
## Local preview
 
Clone the repo and open `index.html` in a browser, or run a local server:
 
```bash
python3 -m http.server 8000
```
 
Then visit `http://localhost:8000`.
