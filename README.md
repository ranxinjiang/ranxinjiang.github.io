# ranxinjiang.github.io

Personal portfolio site for **Ran Xin Jiang**.

**Live Site:** [ranxinjiang.github.io](https://ranxinjiang.github.io)

## About

My work sits at the intersection of project management, data analytics, and operations — turning ambiguous problems into workable systems. This site collects my experience, projects, and certifications.

## Built With

Hand-built with HTML, CSS, and JavaScript. No framework, no build step. Hosted on GitHub Pages.

## Structure

```

├── experience.html                 Experience timeline

├── certs/                          Certificate PDFs
├── projects/                       Per-project images and downloads
│   ├── nyc-warehouse/
│   ├── aws-pipeline/
│   ├── buffalo-flights/
│   └── r2e/
```

Pages live at the root; every asset belonging to a project lives in that project's folder under `projects/`.
